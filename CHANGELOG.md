# Echo app changes

The newest version comes first. The release workflow copies the section of the
version it publishes into the release notes, which the app shows in its update dialog.

## 0.4.0
Voice for the call simulator: Echo can speak with the phone's voices, including European accents (German, Dutch, Italian, Spanish…), and listen to you with the phone's speech recognition. Echo asks once for the microphone. A refused update is offered again when you come back to Echo (at most every 30 minutes).

## 0.3.2
New app icon: Echo the robot, the mascot of the first Echo, on Echo's blue. Works with themed icons too.

## 0.3.1
GlobalExam sign-in: the GlobalExam browser looks like a plain browser, the keyboard types into the page you see, sign-in pop-ups open, and « Back to Echo » moves to the top so it never hides a button.

## 0.3.0
Updates from inside the app: Echo checks for a new version at start and installs it in two taps. Echo can bring its own GlobalExam page reader, so most fixes no longer need a new app.

## 0.2.0
GlobalExam on the phone: a second browser behind Echo, where you sign in once; Echo reads and taps it like the desktop app's browser.

## 0.1.1
App icon.

## 0.1
Echo full screen, opens ELSA, Netflix and Prime Video, adds files.
