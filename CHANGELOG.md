# Echo app changes

The newest version comes first. The release workflow copies the section of the
version it publishes into the release notes, which the app shows in its update dialog.

## 0.7.0
Natural voices: the same human-sounding voices as Microsoft Edge's "Read aloud", through your own free Azure Speech key. In Echo, Voice options › Set up natural voices opens a box where you paste the key; it is checked with Azure and kept on this phone only (Echo never sees it). If Azure doesn't answer (no internet, monthly quota used up), the phone's voice says the line at once.

## 0.6.0
More natural voices: Echo now picks the most natural voice of the phone for each language (the engine's quality mark, and Google's online voices while you are online) instead of the first offline voice, which was often the oldest and most robotic one. Echo can also show every voice of the phone so you choose the one you prefer. If a voice you chose needs the internet and you are offline, the best offline voice reads instead.

## 0.5.0
Safer app: now a release build signed with Echo's own private key, instead of the public debug key that made Google Play Protect warn about it. One-time step: this version cannot install over the old one. Uninstall Echo first (long press on the icon, then Uninstall), then install this version from the Echo-app releases page. You will sign in again once to Claude, GlobalExam and Netflix. After that, updates install as before.

## 0.4.1
New icon: Echo the robot, redrawn softer and simpler on sky blue, with a matching themed icon. On Android 12 and later, the launch screen shows it and Echo hops once and blinks.

## 0.4.0
Voice for the call simulator: Echo can speak with the phone's voices, including European accents (German, Dutch, Italian, Spanish…), and listen to you with the phone's speech recognition. Echo asks once for the microphone. A refused update is offered again when you come back to Echo (at most every 30 minutes).

## 0.3.2
New app icon: Echo the robot, the mascot of the first Echo, on Echo's blue. Works with themed icons too.

## 0.3.1
GlobalExam sign-in: the GlobalExam browser looks like a plain browser, the keyboard types into the page you see, sign-in pop-ups open, and « Back to Echo » moves to the top so it never hides a button.

## 0.3.0
Updates from inside the app: Echo checks for a new version at start and installs it in two taps. Echo can bring its own GlobalExam page reader, so most fixes no longer need a new app.

## 0.2.0
GlobalExam on the phone: a second browser behind Echo, where you sign in once; Echo reads and taps it like the desktop app's browser.

## 0.1.1
App icon.

## 0.1
Echo full screen, opens ELSA, Netflix and Prime Video, adds files.
